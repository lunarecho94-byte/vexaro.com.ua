# URBAN — Однотоварний / Мульти-каталог преміум взуття (Next.js 14 App Router)

Нова архітектура магазину URBAN з підтримкою SSR/ISR, Schema.org, Meta Conversions API (CAPI), Nova Poshta та Telegram-сповіщень.

## Основні характеристики:
- **Швидкість та SEO**: SSR та ISR для всіх категорій і товарів, Schema.org Product з Offer та BreadcrumbList.
- **Відсутність AI-слопу**: Factual український копірайтинг, реальні умови повернення (14 днів) та доставки Новою Поштою (1–2 дні), без фальшивих таймерів і вигаданих відгуків.
- **Каталог товарів**: 7 386 реальних моделей взуття з живими розмірними сітками.
- **Кошик та оформлення**: Розрахунок замовлення, підтримка міст і відділень Нової Пошти, автоматична українська маска телефону `+38 (0XX) XXX-XX-XX`.
- **Рекламна аналітика (Meta Pixel + CAPI)**: Браузерне та серверне відстеження події `Purchase` з єдиним `event_id` для дедуплікації. Захист від повторної відправки при перезавантаженні сторінки подяки.
- **SEO інфраструктура**: Динамічний `sitemap.xml` на всі доступні моделі, `robots.txt` з `noindex, nofollow` для кошика, оформлення та сторінок подяки.

## Запуск:
```bash
# Встановлення залежностей
npm install

# Імпорт товарів (генерує src/data/products.json та meta.json)
npm run import

# Запуск локального сервера
npm run dev

# Production збірка
npm run build
npm start
```
